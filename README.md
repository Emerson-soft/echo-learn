# Echo Learn

criar um app para estudar o shadowing que é uma técnica em inglês para aprender, o app precisa receber uma url do youtube, e cortar o video em frases para repetir a fala, a legenda deve aparecer em baixo e pode ser desativado, e o microfone vai pode ser ativado para falar e ter uma nota de quanto bom estar a fala
